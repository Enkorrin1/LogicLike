# LogicLike Privacy Policy Draft

LogicLike is a children's learning app for short logic, math, focus, and memory
practice. This draft documents the current local-first implementation and must
be reviewed before store submission.

## Data Stored On Device

The app stores family profile data locally on the device:

- child name,
- age range,
- learning goal,
- lesson progress,
- stars, streak, XP, and stickers,
- practice history such as completed lessons, minutes, hints, mistakes, and
  answer accuracy.

## Data Sharing

The current app implementation does not send this data to a backend service and
does not include third-party analytics, ads, or tracking SDKs.

## Parent Controls

Parents can view practice history and recommendations in the parent screen.
Parents can reset the local profile from settings, which clears local progress
and returns the app to onboarding.

## Future Review Required

If backend sync, subscriptions, analytics, crash reporting, push notifications,
or account login are added, this policy must be updated before release.
