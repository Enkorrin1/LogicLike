# LogicLike Localization Guide

Source locale: Russian (`ru`).
First target locale: English (`en`).

Voice: warm, concise, playful, and clear for a family edtech product. Child-facing copy can feel adventurous; parent-facing copy should stay calm and practical.

Glossary:
- `LogicLike` is not translated.
- `Задание дня` -> `Daily quest`.
- `Миссия` -> `Mission`.
- `Семейная подписка` -> `Family subscription`.
- `Родителю` -> `Parent`.
- Prices currently stay in RUB because billing is product-specific and needs business/legal review before regional pricing.

Rules:
- Keep buttons short.
- Use ICU plurals for counts.
- Keep daily challenge content faithful to the underlying learning mechanic.
- Do not translate asset names, route ids, challenge ids, or plan enum names.
